# DM企画サマリー アプリ

毎月のDM施策を、チームで固める「起点」の企画サマリーをWebアプリでリアルタイムにDM施策を管理するツールです。
毎月Excelを何個も開かずに、**過去月も一元閲覧**でき、施策の**正式名・素材コードを自動生成**します。

## 特長（MVP：企画サマリー基盤＋履歴）
- ポチポチ選択でどんどん埋められる軽量入力（会議しながら共同編集）
- 4セクション：① 今月実施 / ② 次月持越し / ③ 今後へ持越し / アイデア候補
- **素材コード自動採番＋正式施策名の自動生成**
  例）カテゴリ「お誕生日DM(DMB)」＋連番179 → `2609_お誕生日_発送DM_RO①_DMB179` / 素材コード `DMB0000179`
- 集計の自動計算（施策数・RO/テスト本数・想定件数合計）
- 履歴：対象月を切替、「＋新規月」で前月コピー作成
- 軽い排他制御：`○○さんが編集中` 表示。閲覧者は自動更新（5秒ごと）

## データの置き場所（重要）
外部クラウドDBは使いません。データは **社内共有フォルダの中のJSONファイル**（`202609.json` など）だけに保存します。
- ブラウザの「フォルダ直結（File System Access API）」で、選んだ共有フォルダを直接読み書きします。
- **対応ブラウザ：Microsoft Edge / Google Chrome**（Firefox/Safari非対応）
- 共有フォルダが OneDrive / SharePoint 同期の場所なら、保存＝全員へほぼ自動同期されます。

### ローカルで試す（実機確認用）
1. このフォルダの **`起動.bat`** をダブルクリック（Python が必要。黒い画面が出て、ブラウザが自動で開きます）。
2. 開かない場合は Edge/Chrome で `http://localhost:8777/index.html` を開く。
3. 終了は黒い画面（コマンドプロンプト）を閉じるだけ。
> ※ `index.html` を直接ダブルクリック（file://）だと「フォルダ直結」が使えないため、必ず `起動.bat` 経由（localhost）で開いてください。

### 使い方
1. アプリを開く（GitHub Pages のURL）。
2. 右上「📁 共有フォルダに接続」→ チームで決めた共有フォルダを選択。
3. お名前を入力。
4. 「＋新規月」で当月を作成（前月コピー可）。
5. 「編集を開始」→ 入力 → 「💾保存」。保存すると共有フォルダのJSONに書き込まれ、全員に反映されます。

> フォルダ未接続でも「お試しモード」でこの端末に一時保存（localStorage）されます。共有には接続が必要です。

## 公開（GitHub Pages）
ビルド不要の静的サイトです。リポジトリを作成し、Settings → Pages で公開ブランチを指定するだけ。
```
index.html
css/styles.css
js/masters.js
js/storage.js
js/app.js
```

## 今後の拡張（合意済みの全体像）
この企画サマリーを起点に、合意後に各Excel／貼付用テキストを生成する機能を順次追加予定：
- ② 案件共有シート「施策一覧_電話」への一括貼付テキスト
- ③ 見積もり依頼（印刷会社向け）テンプレ生成
- ⑥ リスト定義書（AIMSTAR）— **除外ID（当月/前月発送PIN）を素材コードから自動生成**し「1個直すと全部直す」を根絶
- ④ タスク管理表への連携、⑤ 発送スケジュール(PDF)取込による日程反映
